# doc-style-portfolio

A technical documentation-style developer portfolio built with **Next.js 15**, **TypeScript**, and **Tailwind CSS v4**, reverse-engineered from the [`aihero.dev`](https://www.aihero.dev/skills) design system with a **teal primary typography and accent system**.

## ✨ Features

- **IDE & Documentation Layout**: 2-column layout with fixed 240px left sidebar, section index telemetry, and mobile responsiveness.
- **Teal Palette Edition**: Dual-mode color system with Ice Teal (`#E6FAF8` / `#CCFBF1`) on dark backgrounds and Deep Forest Teal (`#0F2F2E`) on light surfaces.
- **GitHub Contribution Heatmap**: 16-week live commit heatmap with teal intensity gradient and daily commit count tooltips.
- **Problem & Solution Drawers**: Expandable engineering rationale blocks on projects.
- **Craft & Systems Showcase**: UI/UX systems, logo monograms, and micro-interactions with live color swatches and framerate badges.
- **Copyable Terminal Widgets**: One-click copy for `$ npx` and `$ claude` commands.
- **Dark & Light Mode**: Seamless theme switching with local storage persistence and zero-FOUC initialization.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: Tailwind CSS v4, Motion
- **Icons**: Lucide React
- **Typography**: DM Sans & JetBrains Mono
